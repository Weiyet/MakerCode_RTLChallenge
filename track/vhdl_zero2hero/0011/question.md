# Full adder

**Difficulty:** ⭐⭐ · **Topics:** carry logic

## Problem
`(cout, sum) = a + b + cin`.

## Interface
| Port | Dir | Type | Description |
|------|-----|------|-------------|
| `a`, `b`, `cin` | in  | std_logic | operands + carry in |
| `sum`  | out | std_logic | sum bit |
| `cout` | out | std_logic | carry out |
