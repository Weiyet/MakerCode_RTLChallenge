# Half adder

**Difficulty:** ⭐ · **Topics:** xor/and

## Problem
`sum = a xor b`, `cout = a and b`.

## Interface
| Port | Dir | Type | Description |
|------|-----|------|-------------|
| `a`, `b` | in  | std_logic | operands |
| `sum`    | out | std_logic | `a xor b` |
| `cout`   | out | std_logic | `a and b` |
